Калькулятор эффективности товарных категорий

Введите данные по категориям за выбранный период. Калькулятор рассчитает валовую прибыль, маржинальность, средний чек, CPO, ДРР, прибыль после рекламы и ROMI — и отсортирует категории по прибыли после рекламных расходов.

Показатели отражают текущий срез за выбранный период. Это не окончательные данные для масштабирования.

Период анализа

⚠ Все данные по товарным категориям должны быть указаны за один и тот же период. Не сравнивайте показатели, рассчитанные за разные даты.
Укажите обе даты, и дата начала не должна быть позже даты окончания.
Можно добавить до 20 категорий. Названия можно менять: например, «Тормозные колодки», «Фильтры», «Амортизаторы», «Масло», «Оптика».

Как считаются показатели

  • Валовая прибыль = выручка − закупочная стоимость проданных товаров.
  • Маржинальность = валовая прибыль / выручка × 100%.
  • Средний чек = выручка / количество оплаченных заказов.
  • CPO = рекламные расходы / количество оплаченных заказов.
  • ДРР = рекламные расходы / выручка × 100%.
  • Прибыль после рекламы = валовая прибыль − рекламные расходы. Это не чистая прибыль бизнеса: аренда, зарплаты, налоги, логистика и другие операционные расходы здесь не учтены.
  • ROMI = прибыль после рекламы / рекламные расходы × 100%. ROMI по валовой прибыли за вычетом рекламных расходов.
Важно: калькулятор показывает финансовый результат товарных категорий за выбранный период. Он помогает сравнить их текущую эффективность, но не определяет, какую категорию следует масштабировать.
